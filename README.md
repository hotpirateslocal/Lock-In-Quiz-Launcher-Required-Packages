# Launcher required — Quiz installation packages

> **These files are NOT standalone app downloads. Downloading a package alone does not give you a usable Quiz. The latest Lock In Launcher is required to install and start Lock In Quiz.**

## Start with Launcher

**[Download Lock In Launcher from the official download page](https://github.com/hotpirateslocal/Lock-In-Quiz-Releases)**, install it, then use its **Download** or **Update** button for Quiz.

This repository is the delivery location used by Launcher. It is not the normal download page. Do not download these packages as a way to skip Launcher: Windows setup checks for a compatible Launcher, and Quiz checks through Launcher before opening, including when started from a desktop shortcut.

Offline use remains available indefinitely after installation, unless Launcher already knows a required update is pending. A direct package download does not bypass update checks or Launcher requirements.

The files are publicly accessible so Launcher can retrieve them without an account. Public availability does not make them standalone applications. This repository contains no application source or user saves.
